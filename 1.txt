Okay, here are examples of how to structure your requests in Postman for all the routes defined in your backend code.

I. Postman Setup

Environment: Create a Postman Environment (e.g., "Backend Dev") to store variables.

Variables: Add the following variables to your environment:

baseUrl: http://localhost:5000 (or your server's address and port)

authToken: (Leave empty initially, will be set after sign-in)

invoiceId: (Leave empty, set after creating an invoice)

poId: (Leave empty, set after creating a purchase order)

stockEntryId: (Leave empty, set after creating a stock entry)

Select Environment: Make sure your created environment is selected in the top-right corner of Postman.

II. Authentication Requests (/api/auth)

Sign Up (Register User)

Purpose: Create a new user account.

Method: POST

URL: {{baseUrl}}/api/auth/signup

Headers:

Content-Type: application/json

Body: (Select raw and JSON)

{
    "username": "testuser",
    "password": "password123"
}


Tests (Optional but Recommended): Add this in the "Tests" tab to automatically save the token:

pm.test("Status code is 201", function () {
    pm.response.to.have.status(201);
});
if (pm.response.code === 201) {
    var jsonData = pm.response.json();
    if (jsonData.token) {
        pm.environment.set("authToken", jsonData.token);
        console.log("Auth Token set!");
    }
}

III. Invoice Requests (/api/invoices)

(Remember to Sign In first to get a valid authToken)

Create Invoice

Purpose: Add a new invoice record with an optional file upload.

Method: POST

URL: {{baseUrl}}/api/invoices

Headers:

Authorization: Bearer {{authToken}}

(Postman automatically sets Content-Type: multipart/form-data when using form-data)

Body: (Select form-data)

companyName (Text): Tech Solutions Inc.

vendorName (Text): Component Supplies Ltd.

address (Text): 123 Supply Street, Techville

totalAmount (Text): 1575.50

purchaseDate (Text): 2023-10-27 (YYYY-MM-DD format or ISO string)

orderOrSerialNumber (Text): ORD-98765

contactNumber (Text): 555-123-4567

additionalDetails (Text): Urgent order for Project X.

allowEditing (Text): false

products (Text): [{"productName":"Laptop","serialNumber":"LT123","warrantyYears":1,"quantity":1,"price":1200},{"productName":"Keyboard","quantity":5,"price":75.10}] (Note: Send the array as a JSON string)

invoiceFile (File): (Click 'Select Files' and choose your PDF/JPG invoice file)

Tests (Optional): Save the ID of the created invoice:

if (pm.response.code === 201) {
    var jsonData = pm.response.json();
    if (jsonData._id) {
        pm.environment.set("invoiceId", jsonData._id);
        console.log("Invoice ID set: " + jsonData._id);
    }
}

Get All Invoices

Purpose: Retrieve all invoices created by the logged-in user.

Method: GET

URL: {{baseUrl}}/api/invoices

Headers:

Authorization: Bearer {{authToken}}

Body: None

Get Single Invoice

Purpose: Retrieve details of a specific invoice.

Method: GET

URL: {{baseUrl}}/api/invoices/{{invoiceId}} (Make sure invoiceId is set in your environment)

Headers:

Authorization: Bearer {{authToken}}

Body: None

Update Invoice

Purpose: Modify an existing invoice (can include changing text fields and/or uploading a new file, which deletes the old one).

Method: PUT

URL: {{baseUrl}}/api/invoices/{{invoiceId}}

Headers:

Authorization: Bearer {{authToken}}

Body: (Select form-data) - Include only the fields you want to change.

vendorName (Text): Updated Vendor Name LLC

additionalDetails (Text): Updated details.

products (Text): [{"productName":"Laptop","serialNumber":"LT123-UPD","warrantyYears":2,"quantity":1,"price":1250}] (Example: updating product details)

invoiceFile (File): (Optional: Select a new file if you want to replace the existing one)

Note: If you don't send the invoiceFile field, the existing file (if any) will remain associated with the invoice.

Delete Invoice

Purpose: Remove an invoice record (also attempts to delete the associated file).

Method: DELETE

URL: {{baseUrl}}/api/invoices/{{invoiceId}}

Headers:

Authorization: Bearer {{authToken}}

Body: None
